# L'ancienne charte

Ce dossier reçoit, pendant la phase 4 de la charte V2 (à partir du 25/11/2026), ce que la
nouvelle charte (`brand/`) remplace. Rien n'est supprimé : tout ce qui sort du site est rangé ici.

- `atelier-theme-jetons-sombres.css` : la palette nuit et cuivre de l'atelier (`--c-*`), telle
  qu'elle était dans `src/app/(atelier)/theme.css`. Les noms `--c-*` existent toujours, ils
  pointent maintenant vers les jetons `--m-*`.

Le grand rangement (anciennes polices, `tokens.css` crème, mails) a lieu en phase 7.
