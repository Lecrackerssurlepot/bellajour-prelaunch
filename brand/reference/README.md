# La référence visuelle

`duplicata-essai-photos.html` est la copie de l'artefact « Essai photos » (duplicata, version du
26/11/2026, https://claude.ai/artifact/14BmVZUw9UeykBNiLtBkE8). C'est **la seule référence visuelle**
du site et de la charte : chaque page portée est comparée à elle, captures côte à côte.

On l'ouvre dans un navigateur, tel quel. Si l'artefact change, on recopie la nouvelle version ici
avec la date, et on le note dans la fiche O.
