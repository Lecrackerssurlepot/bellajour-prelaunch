### Corrections faites après les audits

- **T-050 (bloquant) — l'écran noir.** Le contenu est visible par défaut, le JavaScript ne fait
  plus que l'animer. Un script en ligne pose `data-anim` avant le premier affichage ; chaque règle
  qui cache est doublée d'un filet `html:not([data-anim])` **ajouté en fin de fichier**, sans
  toucher à une seule règle existante. Un chien de garde retire l'attribut au bout de 5 s si le
  code client n'a jamais signé, ce qui couvre le cas où le script passe mais pas le bundle.
  Vérifié à l'écran sur `/` (bureau et 375 px) et `/magazine`, en simulant l'absence de script.
- **T-041** — la relève n'écrit plus les tokens entiers dans le journal. Elle balayait 200 dossiers
  chaque matin ; les journaux Vercel accumulaient le mot de passe permanent de chaque cliente.
- **T-042** — la vignette part avec la photo, dans les deux chemins de suppression.
- **T-060** — les quatre images du deuxième écran passent en chargement différé (164 Ko).

### Une correction annulée, et c'est la plus instructive

**T-059** : `preload: false` sur la police italique de 38,9 Ko est **sans effet**. Trois
constructions successives, jusqu'à poser l'option sur TOUTES les déclarations de police du projet :
les quatre mêmes fichiers préchargés, mêmes empreintes, 120,5 Ko inchangés. Annulée plutôt que
laissée dans le code avec un commentaire revendiquant un gain inexistant.
⚠️ Cela met en cause l'optimisation documentée du 27/08 dans `src/app/layout.tsx:14-22`, qui
justifie un `preload: false` par une économie de 75 Ko. Si l'option est inopérante ici, cette
économie n'a jamais eu lieu.
