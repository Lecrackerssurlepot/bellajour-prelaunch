# Ce qui fait « site généré », et ce qu'on fait à la place

Écrit le 21/11/2026. La liste des tics qu'on retrouve sur les sites montés par des outils d'IA ou
des modèles tout faits. Chaque ligne se vérifie à l'œil sur une maquette.

| Le tic | Pourquoi ça se voit | À la place |
|---|---|---|
| Dégradé violet-bleu, halos flous en fond, « orbes » | c'est le fond par défaut de tous les générateurs depuis 2023 | une couleur pleine, une photo, le papier |
| Verre dépoli partout, bordures lumineuses | effet sans sujet | le verre seulement sur ce qui flotte au-dessus d'une image (une barre), jamais sur un bloc de texte |
| Titre centré + sous-titre gris + deux boutons (plein et contour) | le héros de tous les modèles | un titre, une image qui occupe l'écran, un seul bouton |
| Trois cartes à icône alignées (« Rapide · Simple · Sécurisé ») | le bloc « avantages » de tous les sites | un argument par écran, montré par une image, jamais une icône |
| Icônes au trait de bibliothèque (Lucide, Heroicons) en guise d'illustration | elles ne disent rien de la marque | la photo du geste réel |
| Emoji dans les titres, ✨ partout | signe d'un texte généré | aucun emoji sur le site |
| Chiffres ronds sans source (« +10 000 clients heureux ») | invérifiable, et interdit chez nous | un chiffre réel daté, ou rien |
| Phrases en trois temps, vocabulaire creux (« sublimez », « inoubliable », « en quelques clics », « magique ») | la cadence typique d'un texte de modèle | une phrase concrète qui ne pourrait être dite que par nous |
| Tout apparaît en fondu en montant, élément par élément | l'animation par défaut, sans intention | un mouvement par section, qui montre le produit (ouvrir, tourner, rapprocher) |
| Sections d'égale hauteur, même marge partout, tout centré | grille sans rythme | des ruptures d'échelle : une image pleine page, puis un texte serré, puis une double page |
| Inter ou une sans-serif neutre seule | la police par défaut | un vrai couple display + texte choisi pour la marque |
| Photos de banque d'images ou générées (mains trop parfaites, lumière égale) | se reconnaît immédiatement, et ment sur le produit | nos propres prises de vue, avec du grain et de vraies imperfections |
| Maquettes 3D de magazine flottant en biais sur fond uni | le « mockup » générique | le vrai magazine photographié |
| Bandeaux ajoutés au-dessus de la barre, pastilles « Nouveau », compte à rebours | marketing posé par-dessus la page | l'offre de saison dans la section prix, dans le gabarit |
| FAQ de quinze questions en accordéon | remplissage | six questions sur l'accueil, le reste sur `/magazine` |
| Pied de page en quatre colonnes de liens | modèle de base | un colophon : la maison, le contact, les pages légales |

## Le test

Masquer le logo. Si la page pourrait appartenir à une autre marque de livres photo, elle n'est pas
finie.
