## Ce que Mathias a dit
Rien de dit par Mathias sur ce point le 26/10. Constat de la campagne de tests : Claire (école) veut
qu'une photo de soirée ne passe pas sans son accord.

## Ce que j'ai vérifié
- Constaté par la campagne de tests du 26/10 (profils B2B joués), pas un bug.
- Une photo déposée apparaît dans la grille dès l'envoi. Aucun statut « en attente d'accord » n'existe
  dans le code : la seule « attente » trouvée concerne la confirmation technique de l'envoi.
- Le recours existant est la corbeille, après coup (voir T-199 pour ce qui manque autour). La
  campagne note aussi que « Ne pas publier » a été retiré : non revérifié ici.

## Ce que je propose
Un réglage de l'édition, au choix du responsable : « les photos attendent mon accord ». Dans ce mode :
- une photo déposée arrive dans une file « à valider » ;
- le responsable l'accepte ou la refuse ;
- l'atelier ne voit que les photos acceptées.

Question à Mathias, avant tout code : est-ce une promesse ? Si oui, le mode doit être fidèle dans tout
le parcours et le texte légal doit le dire. Si non, on écrit honnêtement que la corbeille agit après
coup, et ce ticket se ferme sans code. C'est lui qui tranche.

Effort : moyen.
