# La marque Bellajour

Ce qui se voit et ce qui se dit. Écrit le 16/11/2026 : avant, ces règles étaient dispersées entre
l'artefact « Charte Bellajour » (09/11), `src/app/CLAUDE.md`, le skill motion périmé, les en-têtes
des scripts de mails et la mémoire de Claude. Aucun fichier de `docs/` ne les portait.

| Fichier | Contenu | À lire avant |
|---|---|---|
| `CHARTE-GRAPHIQUE.md` | les quatre mondes, couleurs, typographie, espacements, rayons, verre, logo, carte cadeau | toute maquette, page ou visuel |
| `MOTION.md` | tempo, durées, courbes, ce qui s'anime et ce qui ne s'anime jamais | toute animation |
| `PIEGES-VISUELS.md` | les règles payées une fois, et leur raison | toute feuille de style |
| `TON.md` | la voix, les règles d'écriture tranchées, où vit le texte de chaque mail, **le nouveau ton des mails à écrire** | tout texte visible, tout mail |
| `STRUCTURE-INFO.md` | comment poser une information : le récapitulatif, les nombres, les dates | tout écran qui montre de l'argent, une date ou un état |
| `A-TRANCHER.md` | 22 contradictions relevées le 09/11, en attente de Mathias | avant de « réparer » une incohérence |

Règles de tenue :
- Le code fait foi ; ces fichiers le décrivent et changent dans le même geste que lui.
- Un fait daté (ce qui est branché, ce qui manque) va dans `docs/reference/ETAT-PRODUCTION.md`, pas ici.
- Le skill `bellajour-brand-motion` et le skill « bellajour-mail » sont périmés (palette, Playfair, « album ») : ne pas les suivre.
